## リリース全体の性格

patch release だが、**機能追加が 3 つ** (お知らせの自動アーカイブ、日の浅いアカウントからのフォローの承認、デッキのクリップのカラム) と、本家の非公開のセキュリティ修正 (`Merge commit from fork` 1 件) を含む。ほかに backend の不具合修正 (センシティブな画像のアイコン・バナー、リンクプレビューの説明文、ローカルを移行先にする Move、サインアップの競合、未ログインのロールポリシー)、ストリームの性能改善、依存の大きな更新 (Sentry SDK v11、NestJS 12、nodemailer 10、pnpm 12、Node の最低版の引き上げ) がある。

セキュリティにかかわる差分は、方針どおり issue を立てない PR で先に塞いだ (#3813)。この doc では、それぞれの差分で本家が何を変えたかと Elythia の対応だけを書く。
